# Тест швидкості

SimplyNet вимірює ваше інтернет-з'єднання, передаючи дані на тестовий сервер і назад та фіксуючи час. Повідомляються три числа:

- **Завантаження** — як швидко дані надходять на ваш пристрій, у Мбіт/с. Більше — краще.
- **Вивантаження** — як швидко ваш пристрій надсилає дані назовні, у Мбіт/с. Більше — краще.
- **Ping** — час на дорогу до сервера й назад, у мілісекундах. Менше —
  краще.

## Вибір постачальника

Розкривний список під кнопкою **Почати тест** обирає, який тестовий бекенд
використовується.

## Порівняння сервісів тесту швидкості

| Характеристика | Cloudflare (за замовчуванням) | Ookla |
|---|---|---|
| Мета вимірювання | Реальна швидкість веб-серфінгу | Абсолютна теоретична пропускна здатність лінії |
| Статус конфіденційності | 100% анонімно. Без відстеження | Збирає IP, місцезнаходження та дані пристрою |
| Технічний метод | Прогресивне завантаження одним потоком | Насичення мережі кількома потоками |
| Найкраще для | Оцінки щоденної роботи інтернету | Перевірки заявлених провайдером швидкостей |

### Через Cloudflare (за замовчуванням)

Використовує публічні кінцеві точки Cloudflare `speed.cloudflare.com`. Не потрібно облікового запису чи додаткової згоди, і не передаються жодні персональні ідентифікатори, окрім звичайної інформації, яку несе будь-який запит до вебсайту (наприклад, ваша IP-адреса, потрібна для доставки відповіді).

Це рекомендований варіант для більшості користувачів.

### Через Ookla

Використовує глобальну мережу серверів Ookla speedtest.net — ту саму інфраструктуру, що стоїть за відомим сервісом Speedtest. Сервери Ookla обслуговуються третіми сторонами по всьому світу, тож тест під'єднується до найближчого доступного сервера.

Оскільки це задіює сторонні сервери, вибір Ookla першого разу запитує вашу згоду. **Ookla збирає та передає вашу IP-адресу, ідентифікатори пристрою та дані про місцезнаходження.** Ваш вибір запам'ятовується, тож вас не запитуватимуть знову; ви можете будь-коли повернутися до Cloudflare.

Коли активна Ookla, кнопка **Почати тест** стає бурштиновою — як нагадування, що використовується сторонній бекенд. Cloudflare повертає синю кнопку.

## Поради для точних результатів

- Тестуйте через Wi-Fi або мобільні дані залежно від того, що хочете виміряти.
- Закрийте інші застосунки, які можуть використовувати мережу.
- Запустіть тест кілька разів — результати змінюються залежно від умов мережі та навантаження на сервер.
- Дуже швидкісні канали можуть обмежуватися пристроєм або методом тестування, а не вашим фактичним з'єднанням.

## Конфіденційність

Результати зберігаються лише на вашому пристрої в розділі **Попередні вимірювання**. Ви можете будь-коли очистити їх у розділі історії. SimplyNet не завантажує ваші результати нікуди.
