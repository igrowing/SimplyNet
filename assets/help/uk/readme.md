# SimplyNet: сканер і діагностика мережі

## 🔍 Виявіть кожен пристрій у вашій мережі

Ви коли-небудь замислювалися, що насправді підключено до вашого WiFi? SimplyNet дає повну картину вашої мережі за лічені секунди.

## ЩО ЦЕ ВМІЄ?

- ✓ Сканування мережі — блискавично знаходить усі активні хости у вашій локальній мережі (LAN)
- ✓ Сканування портів — перевіряє, які служби працюють на будь-якому хості
- ✓ Діагностика мережі — вбудовані Ping, пошук DNS та розширені інструменти
- ✓ Пошук і перевірка ваших пристроїв IoT — підписка та публікація на брокері MQTT

## ЧОМУ ВАМ ЦЕ СПОДОБАЄТЬСЯ

- Блискавично швидко — сканування завершується за секунди
- Жодного безладу — чистий та інтуїтивний інтерфейс
- Працює в локальній мережі — хмара не потрібна, жодного стеження
- Гнучке ведення журналів — вмикайте/вимикайте журналювання, переглядайте, що і коли відбувалося
- Зручно для розробників — ідеально як для ІТ-фахівців, так і для допитливих користувачів
- 100% безкоштовно — без реклами, без стеження, без набридань. Пожертви вітаються
- Жодної води — лише корисні та справді робочі інструменти
- Відкритий код — прозора розробка силами спільноти. [Перегляньте вихідний код](https://github.com/igrowing/SimplyNet) будь-коли. Натисніть ⭐ «Star» 😊
- Перекладено на 15 мов

## ІДЕАЛЬНО ДЛЯ

- 🏠 Керування домашньою мережею — знайте, що є у вашому WiFi
- 🔒 Мережевої безпеки — помічайте несподівані пристрої
- 👨‍💻 ІТ-фахівців — швидка діагностика та усунення несправностей
- 🛠️ Мережевих адміністраторів — незамінний мережевий інструмент у вашій кишені
- 🧪 Ентузіастів технологій — досліджуйте, як працює ваша мережа

## КОНФІДЕНЦІЙНІСТЬ ПОНАД УСЕ

- Ваші дані залишаються вашими: журнали сканування, історія та профілі мережі зберігаються виключно в локальному сховищі пристрою.
- Жодного стеження чи сторонньої аналітики: цей застосунок не містить жодної телеметрії, жодної реклами та жодних фонових фреймворків стеження.
- Суто функціональний трафік: мережеві пакети (такі як ICMP, DNS або MQTT) залишають ваш телефон лише тоді, коли ви самі запускаєте інструмент. Зовнішні утиліти, такі як тести швидкості та запити WHOIS, підключаються безпосередньо до відповідних публічних сервісів без проміжних серверів стеження.
