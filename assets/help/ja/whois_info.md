# 「Who Is」と DNS 解決とは？

google.com のようなウェブサイトを実際に誰が所有しているのか、気になったことはありませんか？あるいは、ウェブアドレスだけから、スマートフォンが世界の反対側にある正しいコンピューターを自動的に見つけ出す仕組みが気になったことは？

Who Is... ツールを使うとき、あなたはインターネットの管理ディレクトリを覆うカーテンを開けています。このツールは、あらゆるドメインや IP アドレスを調査するために 3 つの主要な機能を使います。

## 1. WHOIS とは？（デジタル版の登記所）

すべてのウェブサイト名（yourwebsite.com など）は、デジタルの不動産です。実際の家を買ったり車を登録したりするのと同じように、登録せずに匿名でドメインを所有することはできません。

WHOIS（文字どおり *「このドメインの責任者は誰か？」* と尋ねること）は、地球上のすべての登録済みドメイン名と IP アドレスの所有者情報を記録した、巨大な公開データベースです。

### たとえ話：陸運局または不動産登記所

陸運局（DMV）でナンバープレートを照会すると、その車の所有者、登録日、連絡方法の記録が得られます。WHOIS 検索はウェブサイトに対してまったく同じことをします。

### どんな情報を見せてくれる？

* 登録者（Registrant）：そのドメインを購入した個人または企業の名前。（注：多くの個人は「プライバシー保護」サービスを使って自宅住所を隠していますが、ホスティング会社の詳細は依然として表示されます。）
* 重要な日付：ウェブサイト名が最初に購入された日、最後に更新された日、そして——最も重要な——有効期限がいつ切れるか。
* 登録業者（Registrar）：所有者がドメインを購入したデジタルの「店」（GoDaddy、Namecheap、Google Domains など）。

## 2. DNS 解決とは？（インターネットの電話帳）

コンピューターは計算が驚くほど得意ですが、言葉は苦手です。`netflix.com` のような名前は理解できません。互いに通信するために、コンピューターは IP アドレス（`142.250.190.46` など）と呼ばれる数値の座標を使います。

一方、人間は名前は得意ですが、ランダムな数字の羅列を覚えるのは苦手です。

**DNS（Domain Name System、ドメインネームシステム）解決**は、この 2 つの世界を結ぶ橋です。人間に優しい名前を、コンピューターに優しい数字へ翻訳します。

### たとえ話：スマートフォンの連絡先アプリ

友人の Alex に電話したいとき、10 桁の電話番号を覚える必要はありません。連絡先リストの「Alex」をタップするだけで、スマートフォンがその名前を数値の電話番号へ自動的に翻訳して発信します。

* DNS はインターネット全体のグローバルな連絡先リストです。* 本アプリでドメインを検索すると、DNS 解決が即座にバックグラウンドで実行され、「おや、google.com は現在 142.250.190.46 という電話番号で稼働しています」と教えてくれます。

## 3. 逆引き解決とは？（デジタル版の発信者番号表示）

では、番号（IP アドレス）を持っていて名前（ウェブサイト）を知りたい場合はどうでしょうか？そこで登場するのが逆引き解決（逆引き DNS、または PTR ルックアップとも呼ばれます）です。

見知らぬコンピューターがあなたの家庭ネットワークに接続しようとしていたり、ネットワークログに奇妙な IP アドレスが見えたりした場合、その IP アドレスを本ツールに貼り付けることができます。アプリはグローバルディレクトリに「この特定の番号にはどのウェブサイト名が登録されているか？」と尋ねます。

### たとえ話：発信者番号表示（または電話番号の逆引き）

スマートフォンが鳴って `1-800-555-0199` のような未知の番号が表示されたら、出るのをためらうかもしれません。しかし、スマートフォンの発信者番号表示がその番号を翻訳して **「Apple サポート」** と表示すれば、誰からの電話かすぐにわかります。

* 逆引き解決は、インターネットアドレスのための発信者番号表示です。
* `172.217.16.142` のような匿名で威圧的な番号を、`google.com` のような親しみやすく認識できる名前へ翻訳し直すことができます。

## 「Who Is...」ツールのまとめ

これら 3 つの機能を組み合わせることで、本ツールはあらゆるデジタルターゲットの完全な「身元調査」を提供します。

1. DNS 解決は、ウェブサイト名の IP アドレス（「電話番号」）を教えてくれます。
2. 逆引き解決は、謎の IP アドレスに対応するウェブサイト名（「発信者番号表示」）を教えてくれます。
3. WHOIS は、その資産の実際の法的所有者、登録業者、有効期限を教えてくれます。
