# スピードテスト

SimplyNet は、テストサーバーとの間でデータを送受信し、その時間を計測することであなたのインターネット接続を測定します。3 つの数値が報告されます。

- **ダウンロード** — データがあなたのデバイスに到達する速さ（Mbps）。高いほど良い。
- **アップロード** — あなたのデバイスがデータを送り出す速さ（Mbps）。高いほど良い。
- **Ping** — サーバーまでの往復遅延（ミリ秒）。低いほど
  良い。

## プロバイダーの選択

**テスト開始**ボタンの下のドロップダウンメニューで、どのテスト
バックエンドを使うかを選択します。

## スピードテストサービスの比較

| 特徴 | Cloudflare（デフォルト） | Ookla |
|---|---|---|
| 測定の目的 | 実際のウェブ閲覧速度 | 回線の絶対的な理論容量 |
| プライバシー状況 | 100% 匿名。追跡なし | IP、位置情報、デバイスデータを収集 |
| 技術的手法 | 単一ストリームのプログレッシブダウンロード | マルチストリームによるネットワーク飽和 |
| 最適な用途 | 日常のインターネット性能の把握 | ISP が広告する速度の検証 |

### Cloudflare 経由（デフォルト）

Cloudflare の公開エンドポイント `speed.cloudflare.com` を使用します。アカウントや追加の同意は不要で、どんなウェブサイトへのリクエストにも伴う通常の情報（応答を届けるために必要な IP アドレスなど）を超える個人識別情報は共有されません。

これはほとんどのユーザーに推奨される選択肢です。

### Ookla 経由

Ookla のグローバルな speedtest.net サーバーネットワーク——よく知られた Speedtest サービスを支える同じインフラ——を使用します。Ookla のサーバーは世界中の第三者によって運営されているため、テストは最も近くて到達可能なサーバーに接続します。

これは第三者のサーバーを伴うため、Ookla を選ぶと初回にあなたの同意を求めます。**Ookla はあなたの IP アドレス、デバイス識別子、位置情報を収集し共有します。** あなたの選択は記憶され、再度尋ねられることはありません。いつでも Cloudflare に戻せます。

Ookla が有効なとき、**テスト開始**ボタンは第三者バックエンドが使用中であることを知らせる合図として琥珀色になります。Cloudflare にすると青いボタンに戻ります。

## 正確な結果を得るためのヒント

- 測定したい内容に応じて、Wi-Fi またはモバイルデータでテストしてください。
- ネットワークを使用している可能性のある他のアプリを閉じてください。
- テストを数回実行してください——結果はネットワークの状態やサーバーの負荷によって変わります。
- 非常に高速な回線は、実際の接続ではなくデバイスやテスト手法によって制限されることがあります。

## プライバシー

結果はあなたのデバイス上の**過去の測定**にのみ保存されます。履歴セクションからいつでも消去できます。SimplyNet はあなたの結果をどこにもアップロードしません。
