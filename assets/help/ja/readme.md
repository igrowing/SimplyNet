# SimplyNet: ネットワークスキャナー＆診断

## 🔍 ネットワーク上のすべてのデバイスを発見

あなたの WiFi に実際に何が接続されているか、気になったことはありませんか？SimplyNet なら数秒でネットワークを丸ごと把握できます。

## 何ができるの？

- ✓ ネットワークスキャン — LAN 上のすべてのアクティブなホストを超高速で発見
- ✓ ポートスキャン — 任意のホストで動作しているサービスを確認
- ✓ ネットワーク診断 — Ping、DNS ルックアップ、高度なツールを内蔵
- ✓ IoT デバイスの発見とテスト — MQTT ブローカーで購読（Subscribe）と発行（Publish）

## きっと気に入る理由

- 超高速 — スキャンは数秒で完了
- ごちゃごちゃなし — すっきりした直感的なインターフェース
- LAN で動作 — クラウド不要、トラッキングなし
- 柔軟なログ記録 — ログの有効／無効を切り替え、いつ何が起きたかを確認
- 開発者にやさしい — IT 専門家にも好奇心旺盛なユーザーにも最適
- 100% 無料 — 広告なし、トラッキングなし、わずらわしさなし。寄付は歓迎します
- 無駄ゼロ — 役に立ち、本当に動くツールだけを収録
- オープンソース — 透明でコミュニティ主導の開発。いつでも[ソースコードをご覧ください](https://github.com/igrowing/SimplyNet)。⭐「Star」をクリック 😊
- 15 言語に翻訳済み

## こんな方に最適

- 🏠 家庭内ネットワーク管理 — WiFi に何があるかを把握
- 🔒 ネットワークセキュリティ — 予期しないデバイスを発見
- 👨‍💻 IT 専門家 — 素早い診断とトラブルシューティング
- 🛠️ ネットワーク管理者 — ポケットに入る必携のネットワークツール
- 🧪 テクノロジー愛好家 — ネットワークの仕組みを探求

## プライバシー最優先

- あなたのデータはあなたのもの：スキャンログ、履歴、ネットワークプロファイルは、デバイスのローカルストレージにのみ保存されます。
- トラッキングや第三者による分析なし：このアプリにはテレメトリも広告もバックグラウンドのトラッキングフレームワークも一切含まれていません。
- 厳密に機能的な通信のみ：ネットワークパケット（ICMP、DNS、MQTT など）は、あなたがツールを能動的に実行したときだけ端末を離れます。速度テストや WHOIS 照会などの外部ユーティリティは、中間のトラッキングサーバーを介さず、それぞれの公開サービスに直接接続します。

**SimplyNet: あなたのネットワークを、もっとよく知っておいたほうがいいから。しゃれのつもりです。**
