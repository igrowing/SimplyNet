# Ping とは？

コンピューターやスマートフォンがウェブサイトに「ping」を送るとき、いったい何が起きているのか気になったことはありませんか？あるいは、ネットが遅くなるとテクニカルサポートがいつも「ping テスト」を実行するよう求めるのはなぜでしょうか？

技術的な響きの名前とは裏腹に、ping はコンピューターネットワーク全体の中で最もシンプルな診断ツールです。ここでは、それが何であり、何をするのか、そして本アプリでどのように機能するのかを、わかりやすい言葉で説明します。

## 1. たとえ話：潜水艦のソナー（またはエコー）

「Ping」という言葉は、実は潜水艦のソナー技術に由来します。

暗い海に浮かぶ潜水艦を想像してください。近くに山や別の船がないかを確認するために、潜水艦は音のパルス——大きな「ピン！」——を水中に発します。

音が物体に当たると、エコー（反響）となって跳ね返ってきます。

エコーが返ってくるまでの時間を測ることで、潜水艦は物体までの距離を正確に計算できます。

エコーが返ってこなければ、潜水艦はそこに何もないとわかります。

デジタルの世界でも、あなたのスマートフォンはまったく同じことをしています。別のコンピューターやウェブサイトに小さなデジタルパルスを送り、そのコンピューターがパルスを跳ね返してくるのを待つのです。

## 2. なぜ必要なのか？

Ping は、接続に関する 3 つの重要な問いに答える手助けをします。

### A.「あのコンピューターは電源が入っていて接続されている？」（可用性）

デバイス（スマートテレビ、ルーター、google.com など）に ping を送って応答が返ってくれば、そのデバイスは電源が入っていてネットワークに接続されているとわかります。ping が失敗する場合は、デバイスの電源が切れている、ケーブルが抜けている、またはファイアウォールが通信を遮断しています。

### B.「私の接続はどれくらい速い？」（レイテンシ）

ping が往復にかかる時間はミリ秒（ms）で測定されます。

* 1〜20 ms：超高速（オンラインゲームやビデオ通話に最適）。
* 20〜100 ms：良好、通常のブラウジング速度。
* 150 ms 超：遅く、カクつきや遅延がある。

### C.「私の接続は安定している？」（パケットロスとジッター）

テニスボールを壁に 10 回投げれば、10 回跳ね返ってくると期待するでしょう。

* ウェブサイトに 50 回 ping を送って 45 回しか返ってこなければ、パケットロス（Packet Loss）は 10% です。これは接続が不安定で、データが途中で失われていることを意味します。
* ある ping は 10 ms なのに別の ping は 500 ms かかる場合、ジッター（Jitter）が大きく、接続が一貫していないことを意味します。

## 3. IP、ホスト名、FQDN：ターゲットの指定方法

本アプリに何かへ ping を送るよう指示するとき、パルスをどこへ送るかを伝える必要があります。3 種類の異なるアドレスを入力できます。

### 1. IP アドレス（GPS 座標）

IP（Internet Protocol）アドレスは、192.168.1.1 や 142.250.190.46 のような数字の並びです。

* 何か：これはネットワーク上のコンピューターの正確な物理アドレスです。コンピューターは IP アドレスしか理解しません。
* たとえ：家の正確な緯度・経度の座標のようなものだと考えてください。非常に正確ですが、人間が覚えるのはとても大変です。

### 2. ホスト名（親しみやすいニックネーム）

ホスト名は、ローカルネットワーク上の 1 台のデバイスに割り当てられた、シンプルで読みやすい名前です。たとえば MyLaptop、OfficePrinter、LivingRoomSpeaker などです。

* 何か：これはローカルなニックネームです。家の中では、スマートフォンに OfficePrinter へ ping を送るよう指示でき、ルーターがそのニックネームを IP アドレスに翻訳します。
* たとえ：「ママの部屋」や「キッチン」と言うようなものです。自分の家の中では完璧に通じますが、他人の家に行って「ママの部屋へ行って」と言っても、どの部屋のことか相手にはわかりません。

### 3. FQDN（完全な郵送先住所）

FQDN は Fully Qualified Domain Name（完全修飾ドメイン名）の略です。例として www.google.com、mail.yahoo.com、support.apple.com などがあります。

* 何か：これはグローバルなインターネット上のサーバーの、完全で公式かつ曖昧さのない名前です。特定のホストのニックネーム（www）と登録済みドメイン（google.com）の両方を含むため、地球上のどのコンピューターを指しているのか一切の混乱がありません。
* たとえ：氏名、番地、都市、国を含む完全な国際郵送先住所のようなものだと考えてください。唯一無二であり、世界のどこからでも通用します。

## 4. Ping ツールの特別な機能

Ping ツールを使うとき、テストの実行方法を完全にコントロールできます。

* Ping の長さをカスタマイズ（回数）：無限に ping を送ったり固定のテストを実行したりする代わりに、ping を送る回数（たとえば 10、50、100 回）を正確に指定できます。これにより、数分間にわたる長期的な安定性テストを実行し、別の部屋に移動したときに Wi-Fi が断続的に切れないかを確認できます。
* いつでも中止（停止ボタン）：100 回の ping 安定性テストを開始したものの、すぐに高いパケットロスやエラーログに気づいた場合、テストが終わるのを座って待つ必要はありません。いつでも停止を押せます。本アプリは即座にバックグラウンドのネットワーク処理を打ち切り、バッテリー消費を止め、完了できた ping の最終的な平均統計をすぐに計算します。
