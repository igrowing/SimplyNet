# 什麼是「Who Is」和 DNS 解析？

你是否想過，像 google.com 這樣的網站究竟是誰擁有的？或者你的手機僅憑一個網址，是如何自動找到世界另一端那台正確的電腦的？

當你使用 Who Is... 工具時，你正在揭開網際網路行政目錄的簾幕。它使用三個主要功能來調查任何網域或 IP 位址。

## 1. 什麼是 WHOIS？（數位地政事務所）

每一個網站名稱（例如 yourwebsite.com）都是一塊數位房地產。就像購買實體房屋或登記汽車一樣，你不能在未註冊的情況下匿名擁有一個網域。

WHOIS（字面意思是詢問*「誰對這個網域負責？」*）是一個龐大的公共資料庫，記錄了地球上每一個已註冊網域名稱和 IP 位址的所有權詳情。

### 類比：監理所或地政事務所

當你在監理所查詢車牌時，你會得到一份紀錄，說明誰擁有這輛車、何時登記以及如何聯絡他們。WHOIS 搜尋對網站做的正是同樣的事。

### 它會向你顯示哪些資訊？

* 註冊人（Registrant）：購買該網域的個人或公司名稱。（注意：許多個人使用「隱私保護」服務來隱藏其住家地址，但代管公司的詳情仍然可見。）
* 重要日期：該網站名稱最初是何時購買的、上次更新是何時，以及——最重要的——何時到期。
* 註冊商（Registrar）：所有者購買該網域的數位「商店」（例如 GoDaddy、Namecheap 或 Google Domains）。

## 2. 什麼是 DNS 解析？（網際網路的電話簿）

電腦在數學上極其聰明，但在語言上很糟糕。它們不理解像 `netflix.com` 這樣的名稱。為了彼此溝通，它們使用稱為 IP 位址的數字座標（例如 `142.250.190.46`）。

而人類恰恰相反，擅長記名稱，但不擅長記住隨機的數字串。

**DNS（Domain Name System，網域名稱系統）解析**就是這兩個世界之間的橋樑。它把一個對人友善的名稱轉譯成一個對電腦友善的數字。

### 類比：你手機的聯絡人應用程式

當你想打電話給朋友 Alex 時，你不會去記他 10 位數的電話號碼。你只需在聯絡人清單中點選「Alex」，你的手機就會自動把這個名稱轉譯成數字電話號碼並撥打。

* DNS 就是整個網際網路的全球聯絡人清單。* 當你在我們的應用程式中搜尋一個網域時，DNS 解析會立即在背景執行，告訴你：「嘿，google.com 目前的電話號碼是 142.250.190.46。」

## 3. 什麼是反向解析？（數位來電顯示）

但如果你有號碼（IP 位址）而想知道名稱（網站）呢？這時就輪到反向解析（也稱為反向 DNS 或 PTR 查詢）出場了。

如果一台陌生的電腦正試圖連線到你的家庭網路，或者你在網路紀錄中看到一個奇怪的 IP 位址，你可以把那個 IP 位址貼到我們的工具中。應用程式會向全球目錄詢問：「哪個網站名稱註冊在這個特定號碼下？」

### 類比：來電顯示（或反向電話查詢）

如果你的手機響了，顯示一個未知號碼如 `1-800-555-0199`，你可能會猶豫要不要接。但如果你手機的來電顯示把那個號碼轉譯過來並顯示**「Apple 支援」**，你立刻就知道是誰打來的。

* 反向解析就是網際網路位址的來電顯示。
* 它讓你能把一個匿名、令人生畏的號碼如 `172.217.16.142` 轉譯回一個友善、可辨識的名稱如 `google.com`。

## 「Who Is...」工具小結

透過組合這三個功能，我們的工具讓你能對任何數位目標進行完整的「背景調查」：

1. DNS 解析告訴你一個網站名稱的 IP 位址（「電話號碼」）。
2. 反向解析告訴你一個神秘 IP 位址對應的網站名稱（「來電顯示」）。
3. WHOIS 告訴你該資產實際的合法所有者、註冊商和到期日期。
