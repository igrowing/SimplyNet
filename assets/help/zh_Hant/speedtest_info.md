# 速度測試

SimplyNet 透過向測試伺服器傳輸資料以及從中接收資料並計時，來測量你的網際網路連線。會回報三個數字：

- **下載** — 資料到達你裝置的速度，單位為 Mbps。越高越好。
- **上傳** — 你裝置發送資料的速度，單位為 Mbps。越高越好。
- **Ping** — 到伺服器的往返延遲，單位為毫秒。越低
  越好。

## 選擇服務供應商

**開始測試**按鈕下方的下拉選單用於選擇使用哪個測試
後端。

## 速度測試服務比較

| 特性 | Cloudflare（預設） | Ookla |
|---|---|---|
| 測量目標 | 真實的網頁瀏覽速度 | 絕對的理論線路容量 |
| 隱私狀態 | 100% 匿名。零追蹤 | 收集 IP、位置和裝置資料 |
| 技術方法 | 單一串流漸進式下載 | 多串流網路飽和 |
| 適合於 | 評估日常網際網路效能 | 驗證 ISP 宣傳的速度 |

### 透過 Cloudflare（預設）

使用 Cloudflare 的公用 `speed.cloudflare.com` 端點。不需要帳戶或額外的同意，除了任何網站請求都會攜帶的正常資訊（例如你的 IP 位址，它是傳遞回應所必需的）之外，不會分享任何個人識別資訊。

對大多數使用者來說，這是建議的選項。

### 透過 Ookla

使用 Ookla 的全球 speedtest.net 伺服器網路——這與知名的 Speedtest 服務背後的基礎架構相同。Ookla 伺服器由世界各地的第三方營運，因此測試會連線到最近且可達的伺服器。

由於這牽涉到第三方伺服器，首次選擇 Ookla 會請求你的同意。**Ookla 會收集並分享你的 IP 位址、裝置識別碼和位置資料。** 你的選擇會被記住，日後不再詢問；你可以隨時切換回 Cloudflare。

當 Ookla 處於啟用狀態時，**開始測試**按鈕會變為琥珀色，提醒你正在使用第三方後端。Cloudflare 會恢復藍色按鈕。

## 取得準確結果的提示

- 根據你想測量的內容，透過 Wi-Fi 或行動數據進行測試。
- 關閉其他可能正在使用網路的應用程式。
- 多執行幾次測試——結果會隨網路狀況和伺服器負載而變化。
- 超高速連線可能受裝置或測試方法的限制，而非你的實際連線。

## 隱私

結果僅儲存在你的裝置上，位於**歷史測量**中。你可以隨時從歷史紀錄區段清除它們。SimplyNet 不會把你的結果上傳到任何地方。
