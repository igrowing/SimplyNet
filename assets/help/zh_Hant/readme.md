# SimplyNet：網路掃描與診斷

## 🔍 發現網路上的每一台裝置

有沒有想過到底有什麼連接到了你的 WiFi？SimplyNet 讓你在幾秒內全面掌握你的網路。

## 它能做什麼？

- ✓ 網路掃描 — 以極快的速度找出區域網路（LAN）中所有活動主機
- ✓ 連接埠掃描 — 查看任意主機上正在執行的服務
- ✓ 網路診斷 — 內建 Ping、DNS 查詢及進階工具
- ✓ 發現並測試你的物聯網（IoT）裝置 — 在 MQTT 代理上訂閱和發佈

## 隱私優先

- 你的資料仍歸你所有：你的掃描日誌、歷史記錄和網路設定檔都嚴格儲存在裝置的本機儲存空間中。
- 無追蹤或第三方分析：本應用程式不含任何遙測、任何廣告和任何背景追蹤框架。
- 嚴格的功能性流量：網路封包（如 ICMP、DNS 或 MQTT）僅在你主動觸發某個工具時才會離開你的手機。諸如測速和 WHOIS 查詢等外部工具會直接連線到各自的公共服務，中間沒有任何追蹤伺服器。

**SimplyNet：因為你最好更了解你的網路。一語雙關。**
