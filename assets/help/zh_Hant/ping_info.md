# 什麼是 Ping？

你是否想過，當你的電腦或手機對某個網站進行「ping」時，到底發生了什麼？或者為什麼當網速變慢時，技術支援總是要你執行「ping 測試」？

儘管這個名稱聽起來很技術化，但 ping 其實是整個電腦網路中最簡單的診斷工具。以下用淺顯易懂的語言介紹它是什麼、有什麼用，以及它在我們應用程式中的運作原理。

## 1. 類比：潛艦聲納（或回音）

「Ping」這個詞其實源自潛艦的聲納技術。

想像一艘潛艦漂浮在黑暗的海洋中。為了查看附近是否有山體或其他船隻，它向水中發出一個聲音脈衝——一聲響亮的「Ping！」。

如果聲音碰到物體，就會以回音的形式反彈回來。

透過測量回音返回所需的時間，潛艦就能精確計算出物體有多遠。

如果沒有回音返回，潛艦就知道那裡什麼都沒有。

在數位世界裡，你的手機也在做完全相同的事。它向另一台電腦或網站發送一個微小的數位脈衝，然後等待那台電腦把脈衝反彈回來。

## 2. 我們為什麼需要它？

Ping 幫助你回答關於連線的三個關鍵問題：

### A.「那台電腦開機並連上網路了嗎？」（可用性）

如果你 ping 某個裝置（例如你的智慧電視、路由器或 google.com）而它有回應，你就知道它已開機並連上網路。如果 ping 失敗，那麼可能是裝置關機了、網路線拔掉了，或者防火牆在阻擋流量。

### B.「我的連線有多快？」（延遲）

你的 ping 完成往返所需的時間以毫秒（ms）為單位測量。

* 1 到 20 ms：飛快（非常適合線上遊戲或視訊通話）。
* 20 到 100 ms：良好，正常的瀏覽速度。
* 超過 150 ms：緩慢、卡頓或有延遲。

### C.「我的連線穩定嗎？」（封包遺失與抖動）

如果你把網球朝牆上丟 10 次，你會期望它彈回 10 次。

* 如果你 ping 一個網站 50 次，卻只有 45 個 ping 返回，那麼你有 10% 的封包遺失率（Packet Loss）。這表示你的連線不穩定，資料在傳輸途中遺失了。
* 如果有些 ping 用了 10 ms，而另一些用了 500 ms，那麼你的抖動（Jitter）很高，意味著你的連線不一致。

## 3. IP、主機名稱和 FQDN：如何指定你的目標

當你要我們的應用程式去 ping 某個東西時，你必須告訴它把脈衝發送到哪裡。你可以輸入三種不同類型的位址：

### 1. IP 位址（GPS 座標）

IP（Internet Protocol）位址是一串數字，例如 192.168.1.1 或 142.250.190.46。

* 它是什麼：這是網路上一台電腦的精確實體位址。電腦只理解 IP 位址。
* 類比：可以把它想像成一棟房子精確的經緯度座標。它非常準確，但對人來說很難記住。

### 2. 主機名稱（Hostname，友善的暱稱）

主機名稱是指派給區域網路上單一裝置的一個簡單、易讀的名稱，例如 MyLaptop、OfficePrinter 或 LivingRoomSpeaker。

* 它是什麼：這是一個本地暱稱。在家裡，你可以要手機去 ping OfficePrinter，你的路由器會把這個暱稱轉譯成它的 IP 位址。
* 類比：就像說「媽媽的房間」或「廚房」。在你自己家裡完全好用，但如果你到陌生人家裡說「去媽媽的房間」，他們就不知道你指的是哪個房間。

### 3. FQDN（完整的郵寄位址）

FQDN 是 Fully Qualified Domain Name（完整網域名稱）的縮寫。例如 www.google.com、mail.yahoo.com 或 support.apple.com。

* 它是什麼：這是全球網際網路上一台伺服器完整、正式、無歧義的名稱。因為它同時包含具體的主機暱稱（www）和已註冊的網域（google.com），所以對於你所指的是地球上哪台電腦，毫無混淆。
* 類比：可以把它想像成一個完整的國際郵寄位址，包括姓名、街道、城市和國家。它是唯一的，並且在世界任何地方都能用。

## 4. Ping 工具的特殊功能

當你使用 Ping 工具時，你可以完全掌控測試的執行方式：

* 自訂 Ping 的時長（次數）：你不必無限地 ping 或執行固定的測試，而是可以精確指定 ping 多少次（例如 10、50 或 100 次）。這讓你能在幾分鐘內執行長時間的穩定性測試，看看當你走到另一個房間時，你的 Wi-Fi 是否會出現間歇性斷線。
* 隨時中止（停止按鈕）：如果你啟動了一個 100 次的 ping 穩定性測試，但立刻發現了高封包遺失率或錯誤紀錄，你不必枯等測試結束。你可以隨時點選停止。我們的應用程式會立即切斷背景的網路程序，停止耗電，並立即計算出那些成功完成的 ping 的最終平均統計資料。
