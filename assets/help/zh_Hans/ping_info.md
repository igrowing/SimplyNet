# 什么是 Ping？

你是否想过，当你的电脑或手机对某个网站进行"ping"时，到底发生了什么？或者为什么当网速变慢时，技术支持总是让你运行"ping 测试"？

尽管这个名字听起来很技术化，但 ping 其实是整个计算机网络中最简单的诊断工具。下面用通俗易懂的语言介绍它是什么、有什么用，以及它在我们应用中的工作原理。

## 1. 类比：潜艇声呐（或回声）

"Ping"这个词其实来自潜艇的声呐技术。

想象一艘潜艇漂浮在黑暗的海洋中。为了查看附近是否有山体或其他船只，它向水中发出一个声音脉冲——一声响亮的"Ping！"。

如果声音碰到物体，就会以回声的形式反弹回来。

通过测量回声返回所需的时间，潜艇就能精确计算出物体有多远。

如果没有回声返回，潜艇就知道那里什么都没有。

在数字世界里，你的手机也在做完全相同的事情。它向另一台电脑或网站发送一个微小的数字脉冲，然后等待那台电脑把脉冲反弹回来。

## 2. 我们为什么需要它？

Ping 帮助你回答关于连接的三个关键问题：

### A. "那台电脑开机并联网了吗？"（可用性）

如果你 ping 某个设备（比如你的智能电视、路由器或 google.com）并且它有回应，你就知道它已开机并连接到网络。如果 ping 失败，那么可能是设备关机了、网线拔掉了，或者防火墙在阻挡流量。

### B. "我的连接有多快？"（延迟）

你的 ping 完成往返所需的时间以毫秒（ms）为单位测量。

* 1 到 20 ms：飞快（非常适合在线游戏或视频通话）。
* 20 到 100 ms：良好，正常的浏览速度。
* 超过 150 ms：缓慢、卡顿或有延迟。

### C. "我的连接稳定吗？"（丢包与抖动）

如果你把网球朝墙上扔 10 次，你会期望它弹回 10 次。

* 如果你 ping 一个网站 50 次，却只有 45 个 ping 返回，那么你有 10% 的丢包率（Packet Loss）。这意味着你的连接不稳定，数据在传输途中丢失了。
* 如果有些 ping 用了 10 ms，而另一些用了 500 ms，那么你的抖动（Jitter）很高，意味着你的连接不一致。

## 3. IP、主机名和 FQDN：如何指定你的目标

当你让我们的应用去 ping 某个东西时，你必须告诉它把脉冲发送到哪里。你可以输入三种不同类型的地址：

### 1. IP 地址（GPS 坐标）

IP（Internet Protocol）地址是一串数字，比如 192.168.1.1 或 142.250.190.46。

* 它是什么：这是网络上一台电脑的精确物理地址。电脑只理解 IP 地址。
* 类比：可以把它想象成一座房子精确的经纬度坐标。它非常准确，但对人来说很难记住。

### 2. 主机名（Hostname，友好的昵称）

主机名是分配给本地网络上单个设备的一个简单、易读的名字，比如 MyLaptop、OfficePrinter 或 LivingRoomSpeaker。

* 它是什么：这是一个本地昵称。在家里，你可以让手机去 ping OfficePrinter，你的路由器会把这个昵称翻译成它的 IP 地址。
* 类比：就像说"妈妈的房间"或"厨房"。在你自己家里完全好用，但如果你到陌生人家里说"去妈妈的房间"，他们就不知道你指的是哪个房间。

### 3. FQDN（完整的邮政地址）

FQDN 是 Fully Qualified Domain Name（完全限定域名）的缩写。例如 www.google.com、mail.yahoo.com 或 support.apple.com。

* 它是什么：这是全球互联网上一台服务器完整、正式、无歧义的名称。因为它同时包含具体的主机昵称（www）和已注册的域名（google.com），所以对于你所指的是地球上哪台电脑，毫无混淆。
* 类比：可以把它想象成一个完整的国际邮寄地址，包括姓名、街道、城市和国家。它是唯一的，并且在世界任何地方都能用。

## 4. Ping 工具的特殊功能

当你使用 Ping 工具时，你可以完全控制测试的运行方式：

* 自定义 Ping 的时长（次数）：你不必无限地 ping 或运行固定的测试，而是可以精确指定 ping 多少次（例如 10、50 或 100 次）。这让你能够在几分钟内运行长时间的稳定性测试，看看当你走到另一个房间时，你的 Wi-Fi 是否会出现间歇性掉线。
* 随时中止（停止按钮）：如果你启动了一个 100 次的 ping 稳定性测试，但立刻发现了高丢包率或错误日志，你不必坐等测试结束。你可以随时点击停止。我们的应用会立即切断后台的网络进程，停止耗电，并立即计算出那些成功完成的 ping 的最终平均统计数据。
