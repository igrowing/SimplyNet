# SimplyNet：网络扫描与诊断

## 🔍 发现网络上的每一台设备

有没有想过到底有什么连接到了你的 WiFi？SimplyNet 让你在几秒内全面掌握你的网络。

## 它能做什么？

- ✓ 网络扫描 — 以极快的速度找出局域网（LAN）中所有活动主机
- ✓ 端口扫描 — 查看任意主机上正在运行的服务
- ✓ 网络诊断 — 内置 Ping、DNS 查询及高级工具
- ✓ 发现并测试你的物联网（IoT）设备 — 在 MQTT 代理上订阅和发布

## 隐私优先

- 你的数据仍归你所有：你的扫描日志、历史记录和网络配置文件都严格保存在设备的本地存储中。
- 无跟踪或第三方分析：本应用不含任何遥测、任何广告和任何后台跟踪框架。
- 严格的功能性流量：网络数据包（如 ICMP、DNS 或 MQTT）仅在你主动触发某个工具时才会离开你的手机。诸如测速和 WHOIS 查询等外部实用工具会直接连接到各自的公共服务，中间没有任何跟踪服务器。
