# 什么是"Who Is"和 DNS 解析？

你是否想过，像 google.com 这样的网站究竟是谁拥有的？或者你的手机仅凭一个网址，是如何自动找到世界另一端那台正确的电脑的？

当你使用 Who Is... 工具时，你正在揭开互联网行政目录的帷幕。它使用三个主要功能来调查任何域名或 IP 地址。

## 1. 什么是 WHOIS？（数字土地登记处）

每一个网站名称（比如 yourwebsite.com）都是一块数字房地产。就像购买实体房屋或注册汽车一样，你不能在不注册的情况下匿名拥有一个域名。

WHOIS（字面意思是询问*"谁对这个域名负责？"*）是一个庞大的公共数据库，记录了地球上每一个已注册域名和 IP 地址的所有权详情。

### 类比：车管所或房地产登记处

当你在车辆管理局（DMV）查询车牌时，你会得到一份记录，说明谁拥有这辆车、何时注册以及如何联系他们。WHOIS 搜索对网站做的正是同样的事情。

### 它会向你展示哪些信息？

* 注册人（Registrant）：购买该域名的个人或公司的名称。（注意：许多个人使用"隐私保护"服务来隐藏其家庭住址，但托管公司的详情仍然可见。）
* 重要日期：该网站名称最初是何时购买的、上次更新是何时，以及——最重要的——何时到期。
* 注册商（Registrar）：所有者购买该域名的数字"商店"（比如 GoDaddy、Namecheap 或 Google Domains）。

## 2. 什么是 DNS 解析？（互联网的电话簿）

电脑在数学上极其聪明，但在语言上很糟糕。它们不理解像 `netflix.com` 这样的名字。为了彼此交流，它们使用称为 IP 地址的数字坐标（比如 `142.250.190.46`）。

而人类恰恰相反，擅长记名字，但不擅长记住随机的数字串。

**DNS（Domain Name System，域名系统）解析**就是这两个世界之间的桥梁。它把一个对人友好的名字翻译成一个对电脑友好的数字。

### 类比：你手机的联系人应用

当你想给朋友 Alex 打电话时，你不会去记他 10 位数的电话号码。你只需在联系人列表中点击"Alex"，你的手机就会自动把这个名字翻译成数字电话号码并拨打。

* DNS 就是整个互联网的全球联系人列表。* 当你在我们的应用中搜索一个域名时，DNS 解析会立即在后台运行，告诉你："嘿，google.com 目前的电话号码是 142.250.190.46。"

## 3. 什么是反向解析？（数字来电显示）

但如果你有号码（IP 地址）而想知道名字（网站）呢？这时就轮到反向解析（也称为反向 DNS 或 PTR 查询）出场了。

如果一台陌生的电脑正试图连接到你的家庭网络，或者你在网络日志中看到一个奇怪的 IP 地址，你可以把那个 IP 地址粘贴到我们的工具中。应用会向全球目录询问："哪个网站名称注册在这个特定号码下？"

### 类比：来电显示（或反向电话查询）

如果你的手机响了，显示一个未知号码如 `1-800-555-0199`，你可能会犹豫要不要接。但如果你手机的来电显示把那个号码翻译过来并显示**"Apple 支持"**，你立刻就知道是谁打来的。

* 反向解析就是互联网地址的来电显示。
* 它让你能把一个匿名、令人生畏的号码如 `172.217.16.142` 翻译回一个友好、可识别的名字如 `google.com`。

## "Who Is..." 工具小结

通过组合这三个功能，我们的工具让你能对任何数字目标进行完整的"背景调查"：

1. DNS 解析告诉你一个网站名称的 IP 地址（"电话号码"）。
2. 反向解析告诉你一个神秘 IP 地址对应的网站名称（"来电显示"）。
3. WHOIS 告诉你该财产实际的合法所有者、注册商和到期日期。
