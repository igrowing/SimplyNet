# 速度测试

SimplyNet 通过向测试服务器传输数据以及从中接收数据并计时，来测量你的互联网连接。会报告三个数字：

- **下载** — 数据到达你设备的速度，单位为 Mbps。越高越好。
- **上传** — 你设备发送数据的速度，单位为 Mbps。越高越好。
- **Ping** — 到服务器的往返延迟，单位为毫秒。越低
  越好。

## 选择服务提供商

**开始测试**按钮下方的下拉菜单用于选择使用哪个测试
后端。

## 速度测试服务对比

| 特性 | Cloudflare（默认） | Ookla |
|---|---|---|
| 测量目标 | 真实的网页浏览速度 | 绝对的理论线路容量 |
| 隐私状态 | 100% 匿名。零追踪 | 收集 IP、位置和设备数据 |
| 技术方法 | 单流渐进式下载 | 多流网络饱和 |
| 适合于 | 评估日常互联网性能 | 验证 ISP 宣传的速度 |

### 通过 Cloudflare（默认）

使用 Cloudflare 的公共 `speed.cloudflare.com` 端点。不需要账户或额外的同意，除了任何网站请求都会携带的正常信息（例如你的 IP 地址，它是传递响应所必需的）之外，不共享任何个人标识符。

对大多数用户来说，这是推荐的选项。

### 通过 Ookla

使用 Ookla 的全球 speedtest.net 服务器网络——这与知名的 Speedtest 服务背后的基础设施相同。Ookla 服务器由世界各地的第三方运营，因此测试会连接到最近且可达的服务器。

由于这涉及第三方服务器，首次选择 Ookla 会请求你的同意。**Ookla 会收集并共享你的 IP 地址、设备标识符和位置数据。** 你的选择会被记住，以后不再询问；你可以随时切换回 Cloudflare。

当 Ookla 处于激活状态时，**开始测试**按钮会变为琥珀色，提醒你正在使用第三方后端。Cloudflare 会恢复蓝色按钮。

## 获得准确结果的提示

- 根据你想测量的内容，通过 Wi-Fi 或移动数据进行测试。
- 关闭其他可能正在使用网络的应用。
- 多运行几次测试——结果会随网络状况和服务器负载而变化。
- 超高速链路可能受设备或测试方法的限制，而非你的实际连接。

## 隐私

结果仅存储在你的设备上，位于**历史测量**中。你可以随时从历史记录部分清除它们。SimplyNet 不会把你的结果上传到任何地方。
