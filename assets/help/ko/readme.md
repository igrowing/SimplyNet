# SimplyNet: 네트워크 스캐너 및 진단

## 🔍 네트워크의 모든 기기를 찾아보세요

내 WiFi에 실제로 무엇이 연결되어 있는지 궁금했던 적 있으신가요? SimplyNet은 몇 초 만에 네트워크 전체를 한눈에 보여줍니다.

## 무엇을 할 수 있나요?

- ✓ 네트워크 스캔 — LAN의 모든 활성 호스트를 초고속으로 찾아냅니다
- ✓ 포트 스캔 — 어떤 호스트에서든 실행 중인 서비스를 확인합니다
- ✓ 네트워크 진단 — Ping, DNS 조회 및 고급 도구 내장
- ✓ IoT 기기 찾기 및 테스트 — MQTT 브로커에서 구독(Subscribe)하고 발행(Publish)

## 좋아하실 이유

- 매우 빠름 — 스캔이 몇 초 만에 완료됩니다
- 군더더기 없음 — 깔끔하고 직관적인 인터페이스
- LAN에서 작동 — 클라우드 불필요, 추적 없음
- 유연한 로깅 — 로깅을 켜고/끄고, 언제 무슨 일이 있었는지 확인
- 개발자 친화적 — IT 전문가와 호기심 많은 사용자 모두에게 안성맞춤
- 100% 무료 — 광고 없음, 추적 없음, 방해 없음. 기부는 환영합니다
- 군더더기 제로 — 유용하고 실제로 작동하는 도구만 담았습니다
- 오픈 소스 — 투명하고 커뮤니티가 주도하는 개발. 언제든지 [소스 코드를 확인하세요](https://github.com/igrowing/SimplyNet). ⭐ "Star"를 눌러 주세요 😊
- 15개 언어로 번역됨

## 이런 분께 딱

- 🏠 홈 네트워크 관리 — 내 WiFi에 무엇이 있는지 파악
- 🔒 네트워크 보안 — 예상치 못한 기기 탐지
- 👨‍💻 IT 전문가 — 빠른 진단과 문제 해결
- 🛠️ 네트워크 관리자 — 주머니 속 필수 네트워크 도구
- 🧪 기술 애호가 — 네트워크가 어떻게 작동하는지 탐구

## 개인정보 보호 우선

- 데이터는 오롯이 사용자의 것: 스캔 로그, 기록, 네트워크 프로필은 오직 기기의 로컬 저장소에만 저장됩니다.
- 추적 및 제3자 분석 없음: 이 앱에는 어떠한 텔레메트리도, 광고도, 백그라운드 추적 프레임워크도 전혀 포함되어 있지 않습니다.
- 철저히 기능적인 트래픽: 네트워크 패킷(ICMP, DNS, MQTT 등)은 사용자가 도구를 직접 실행할 때에만 휴대폰을 벗어납니다. 속도 테스트나 WHOIS 조회 같은 외부 유틸리티는 중간 추적 서버 없이 각각의 공개 서비스에 직접 연결됩니다.
