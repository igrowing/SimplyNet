# 속도 테스트

SimplyNet은 테스트 서버로 데이터를 주고받으며 시간을 측정하여 인터넷 연결을 평가합니다. 세 가지 수치가 보고됩니다:

- **다운로드** — 데이터가 기기에 도달하는 속도로, 단위는 Mbps입니다. 높을수록 좋습니다.
- **업로드** — 기기가 데이터를 내보내는 속도로, 단위는 Mbps입니다. 높을수록 좋습니다.
- **Ping** — 서버까지 왕복 지연 시간으로, 단위는 밀리초입니다. 낮을수록
  좋습니다.

## 제공자 선택

**테스트 시작** 버튼 아래의 드롭다운에서 어떤 테스트 백엔드를
사용할지 선택합니다.

## 속도 테스트 서비스 비교

| 기능 | Cloudflare (기본값) | Ookla |
|---|---|---|
| 측정 목표 | 실제 웹 브라우징 속도 | 절대적 이론상 회선 용량 |
| 개인정보 상태 | 100% 익명. 추적 없음 | IP, 위치, 기기 데이터 수집 |
| 기술적 방식 | 단일 스트림 점진적 다운로드 | 다중 스트림 네트워크 포화 |
| 이상적인 용도 | 일상 인터넷 성능 측정 | ISP 광고 속도 확인 |

### Cloudflare 사용 (기본값)

Cloudflare의 공개 `speed.cloudflare.com` 엔드포인트를 사용합니다. 계정이나 추가 동의가 필요 없으며, 모든 웹사이트 요청이 담고 있는 일반 정보(응답 전달에 필요한 IP 주소 등) 외에는 어떠한 개인 식별자도 공유되지 않습니다.

대부분의 사용자에게 권장되는 옵션입니다.

### Ookla 사용

Ookla의 전 세계 speedtest.net 서버 네트워크를 사용합니다. 잘 알려진 Speedtest 서비스의 기반이 되는 것과 동일한 인프라입니다. Ookla 서버는 전 세계 제3자가 운영하므로, 테스트는 가장 가깝고 연결 가능한 서버에 접속합니다.

이는 제3자 서버가 관여하므로, Ookla를 선택하면 처음 한 번 동의를 요청합니다. **Ookla는 귀하의 IP 주소, 기기 식별자, 위치 데이터를 수집하고 공유합니다.** 선택은 기억되어 다시 묻지 않으며, 언제든지 Cloudflare로 다시 전환할 수 있습니다.

Ookla가 활성화되면 **테스트 시작** 버튼이 제3자 백엔드가 사용 중임을 상기시키기 위해 황색으로 바뀝니다. Cloudflare는 파란색 버튼을 복원합니다.

## 정확한 결과를 위한 팁

- 측정하려는 대상에 따라 Wi-Fi 또는 모바일 데이터로 테스트하세요.
- 네트워크를 사용할 수 있는 다른 앱을 닫으세요.
- 테스트를 몇 번 실행하세요. 결과는 네트워크 상태와 서버 부하에 따라 달라집니다.
- 매우 고속인 회선은 실제 연결보다 기기나 테스트 방식에 의해 제한될 수 있습니다.
