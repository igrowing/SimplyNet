# "Who Is"와 DNS 해석이란 무엇인가요?

google.com 같은 웹사이트를 실제로 누가 소유하는지 궁금했던 적이 있나요? 아니면 휴대폰이 어떻게 웹 주소만으로 지구 반대편의 올바른 컴퓨터를 자동으로 찾는지 궁금했나요?

Who Is... 도구를 사용하면 인터넷의 행정 디렉터리 뒤에 드리운 장막을 걷어올리게 됩니다. 이 도구는 세 가지 주요 기능을 사용해 어떤 도메인이나 IP 주소든 조사합니다.

## 1. WHOIS란 무엇인가요? (디지털 부동산 등기부)

모든 웹사이트 이름(예: yourwebsite.com)은 디지털 부동산의 한 조각입니다. 실제 집을 사거나 자동차를 등록하는 것처럼, 도메인을 등록하지 않고 익명으로 소유할 수는 없습니다.

WHOIS(문자 그대로 *"이 도메인은 누가 책임지는가?"*라고 묻는 것)는 지구상의 모든 등록된 도메인 이름과 IP 주소의 소유 정보를 기록하는 거대한 공개 데이터베이스입니다.

### 비유: 차량 등록소 또는 부동산 등기소

차량 등록소에서 번호판을 조회하면 누가 차를 소유하는지, 언제 등록되었는지, 어떻게 연락하는지에 대한 기록을 얻습니다. WHOIS 검색은 웹사이트에 대해 정확히 같은 일을 합니다.

### 어떤 정보를 보여주나요?

* 등록자(Registrant): 도메인을 구매한 사람이나 회사의 이름. (참고: 많은 개인이 자신의 집 주소를 숨기기 위해 "개인정보 보호" 서비스를 이용하지만, 호스팅 회사의 세부 정보는 여전히 보입니다.)
* 중요한 날짜: 웹사이트 이름이 처음 구매된 정확한 시점, 마지막으로 업데이트된 시점, 그리고 가장 중요하게는 만료되는 시점.
* 등록 대행사(Registrar): 소유자가 도메인을 구매한 디지털 "상점"(예: GoDaddy, Namecheap 또는 Google Domains).

## 2. DNS 해석이란 무엇인가요? (인터넷의 전화번호부)

컴퓨터는 수학에는 엄청나게 뛰어나지만 언어에는 형편없습니다. `netflix.com` 같은 이름을 이해하지 못합니다. 서로 대화하기 위해 IP 주소(예: `142.250.190.46`)라 불리는 숫자 좌표를 사용합니다.

반면 사람은 이름에는 뛰어나지만 무작위 숫자 나열을 외우는 데는 형편없습니다.

**DNS(Domain Name System) 해석**은 이 두 세계를 잇는 다리입니다. 사람에게 친숙한 이름을 컴퓨터에 친숙한 숫자로 변환합니다.

### 비유: 휴대폰의 연락처 앱

친구 Alex에게 전화하려 할 때 10자리 전화번호를 외우지 않습니다. 그냥 연락처 목록에서 "Alex"를 누르면 휴대폰이 그 이름을 숫자 전화번호로 자동 변환해 전화를 겁니다.

* DNS는 전체 인터넷을 위한 글로벌 연락처 목록입니다. * 우리 앱에서 도메인을 검색하면 DNS 해석이 백그라운드에서 즉시 실행되어 알려줍니다: "이봐요, google.com은 현재 전화번호 142.250.190.46에서 운영 중이에요."

## 3. 역방향 해석이란 무엇인가요? (디지털 발신자 표시)

그런데 번호(IP 주소)는 있는데 이름(웹사이트)을 알고 싶다면 어떻게 될까요? 여기서 역방향 해석(역방향 DNS 또는 PTR 조회라고도 함)이 등장합니다.

낯선 컴퓨터가 당신의 홈 네트워크에 연결하려 하거나 네트워크 로그에서 이상한 IP 주소를 본다면, 그 IP 주소를 우리 도구에 붙여넣을 수 있습니다. 앱은 글로벌 디렉터리에 묻습니다: "이 특정 번호에는 어떤 웹사이트 이름이 등록되어 있나요?"

### 비유: 발신자 표시 (또는 역방향 전화 조회)

휴대폰이 울리며 `1-800-555-0199` 같은 알 수 없는 번호가 표시되면 받기를 망설일 수 있습니다. 하지만 휴대폰의 발신자 표시가 그 번호를 변환해 **"Apple 지원"**이라고 표시하면 누가 전화하는지 즉시 알 수 있습니다.

* 역방향 해석은 인터넷 주소를 위한 발신자 표시입니다.
* `172.217.16.142` 같은 익명의 위압적인 번호를 `google.com` 같은 친숙하고 알아볼 수 있는 이름으로 다시 변환할 수 있게 해줍니다.

## "Who Is..." 도구 요약

이 세 가지 기능을 결합하여 우리 도구는 어떤 디지털 대상이든 완전한 "신원 조회"를 제공합니다:

1. DNS 해석은 웹사이트 이름의 IP 주소("전화번호")를 알려줍니다.
2. 역방향 해석은 수수께끼의 IP 주소의 웹사이트 이름("발신자 표시")을 알려줍니다.
3. WHOIS는 그 "부동산"의 실제 법적 소유자, 등록 대행사, 만료 날짜를 알려줍니다.
