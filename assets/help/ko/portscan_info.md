# 포트 스캔이란 무엇인가요?

해커나 보안 전문가는 기기의 취약점을 어떻게 찾을까요?

그들은 포트 스캔이라는 도구를 사용해 이를 수행합니다.

## 1. 비유: 65,536개의 문이 있는 보안 건물

거대하고 보안이 철저한 사무용 건물이나 아파트 단지를 상상해 보세요.

* 호스트(IP 주소 또는 도메인)는 건물의 도로명 주소입니다. 정문까지 데려다줍니다.
* 안으로 들어가면 건물에는 정확히 65,536개의 번호가 매겨진 문(포트라고 함)이 있습니다.
* 각 문 뒤에는 특정 업체나 서비스가 있습니다. 예를 들어 80번 문 뒤에는 웹사이트 관리자가, 554번 문 뒤에는 보안 카메라 스트림이 있습니다.

  💡 포트 스캔은 경비원이 복도를 걸으며 문을 두드리고 어떤 문이 열려 있는지, 잠겨 있는지, 완전히 버려져 있는지 확인하는 것과 같습니다.

문이 열려 있다면 그 뒤에서 서비스가 활발히 실행 중이며 연결을 기다리고 있다는 뜻입니다. 닫혀 있다면 문이 잠겨 있고 안에 아무도 없는 것입니다.

## 2. 대상 선택: 잘 알려진 포트 vs. 사용자 지정 범위

어떤 "문"을 확인할지 선택할 수 있습니다:

### A. 잘 알려진 포트 (메인 로비 확인)

가능한 65,536개의 문 중 대다수는 비어 있습니다. 기본적으로 인터넷은 처음 1,024개의 문을 표준적이고 공식적인 서비스용으로 예약합니다.

* 80번 문: 표준 웹사이트 (HTTP)
* 443번 문: 보안 웹사이트 (HTTPS)
* 21번 문: 파일 공유 (FTP)
* 22번 문: 보안 원격 제어 (SSH)
* 어떻게 도움이 되는가: 잘 알려진 포트를 스캔하는 것은 건물의 메인 로비와 하역장만 확인하는 것과 같습니다. 놀랍도록 빠르며(단 몇 초 소요) 일반 사용자가 찾는 것의 99%를 다룹니다.

### B. 사용자 정의 범위 (모든 방 탐색)

때때로 사용자 지정 앱, 스마트홈 기기 또는 카메라는 눈에 띄지 않기 위해 특이한 문 번호(예: 8080번 문 또는 32400번 문) 뒤에 숨습니다.

* 어떻게 도움이 되는가: 앱에 사용자 지정 범위를 스캔하도록 지시할 수 있습니다. 예를 들어 1번 문부터 2048번 문까지 말이죠. 앱은 숨겨진 서비스를 찾기 위해 그 모든 문을 하나씩 성실하게 두드립니다.

## 3. 프로토콜: TCP vs. UDP

컴퓨터의 "문"은 두 가지 다른 언어를 사용합니다. 설정에 따라 앱은 다른 방식으로 두드립니다:

### 1. TCP (정중한 악수)

TCP(Transmission Control Protocol)는 인터넷에서 가장 일반적인 프로토콜입니다. 100% 정확성을 위해 설계되었습니다.

* 두드리는 방식: 앱이 문을 두드리고, 누군가 열어주기를 기다리고, 악수를 하고, "안녕하세요!"라고 말한 뒤 정중히 떠납니다.
* 비유: 등기 우편을 보내는 것과 같습니다. 누군가 집에 있는지 확인하는 데 매우 신뢰할 수 있지만, "악수"를 완료하는 데 몇 분의 1초가 걸립니다.

### 2. UDP (엽서 던지고 가기)

UDP(User Datagram Protocol)는 순수 속도를 위해 설계되었으며, 종종 실시간 영상 스트림이나 온라인 게임에 사용됩니다.

* 두드리는 방식: 앱이 우편 투입구로 엽서를 던져 넣고 안에서 누군가 소리쳐 답하는지 잠깐 귀를 기울입니다. 악수를 기다리지 않습니다.
* 비유: 종이비행기를 담 너머로 던지는 것과 같습니다. 놀랍도록 빠르지만, 아무도 소리쳐 답하지 않으면 방이 비어 있는지 아니면 종이비행기를 그냥 무시한 것인지 100% 확신하기가 더 어렵습니다.

## 4. 왜 큰 스캔은 그렇게 오래 걸리나요?

*"왜 내 스캔은 이렇게 오래 걸리나요?"* 답은 간단한 계산입니다!

* TCP만 사용해 잘 알려진 포트를 스캔하면 앱은 약 60개의 문을 확인합니다. 순식간에 끝납니다.
* 범위를 1부터 10,000까지 확장하고 TCP와 UDP를 모두 선택하면, 앱은 물리적으로 **20,000**번의 개별 두드림을 수행해야 합니다(TCP용 **10,000**번, UDP용 **10,000**번).

앱은 각 문에서 기기가 응답하는지 확인하기 위해 아주 짧은 순간을 기다려야 하므로(느리게 응답하는 카메라나 라우터를 놓치지 않기 위해), 수만 개의 문을 확인하려면 인내심이 필요합니다.
