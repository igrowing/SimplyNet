# SimplyNet : Scanner réseau et diagnostic

## 🔍 Découvrez chaque appareil de votre réseau

Vous êtes-vous déjà demandé ce qui est réellement connecté à votre WiFi ? SimplyNet vous offre une visibilité complète de votre réseau en quelques secondes.

## QUE FAIT-IL ?

- ✓ Analyse du réseau — Trouvez tous les hôtes actifs de votre LAN à une vitesse fulgurante
- ✓ Analyse des ports — Vérifiez quels services fonctionnent sur n'importe quel hôte
- ✓ Diagnostic réseau — Ping, résolution DNS et outils avancés intégrés
- ✓ Trouvez et testez vos appareils IoT — Abonnez-vous et publiez sur un broker MQTT

## POURQUOI VOUS L'ADOREREZ

- Ultra rapide — Les analyses se terminent en quelques secondes
- Zéro encombrement — Interface épurée et intuitive
- Fonctionne en LAN — Aucun cloud requis, aucun pistage
- Journalisation flexible — Activez/désactivez la journalisation, revoyez ce qui s'est passé et quand
- Pensé pour les développeurs — Parfait aussi bien pour les professionnels de l'informatique que pour les utilisateurs curieux
- 100 % gratuit — Pas de publicité, pas de pistage, aucun tracas. Les dons sont les bienvenus
- Zéro superflu — uniquement des outils utiles et réellement fonctionnels
- Open source — Développement transparent et communautaire. [Consultez le code source](https://github.com/igrowing/SimplyNet) quand vous voulez. Cliquez sur l'⭐ « Star » 😊
- Traduit en 15 langues

## PARFAIT POUR

- 🏠 Gestion du réseau domestique — Sachez ce qui se trouve sur votre WiFi
- 🔒 Sécurité du réseau — Repérez les appareils inattendus
- 👨‍💻 Professionnels de l'informatique — Diagnostic et dépannage rapides
- 🛠️ Administrateurs réseau — L'outil réseau essentiel dans votre poche
- 🧪 Passionnés de technologie — Explorez le fonctionnement de votre réseau

## LA CONFIDENTIALITÉ AVANT TOUT

- Vos données restent les vôtres : vos journaux d'analyse, votre historique et vos profils réseau sont enregistrés strictement dans le stockage local de l'appareil.
- Aucun pistage ni analyse tiers : cette application ne contient aucune télémétrie, aucune publicité et aucun cadre de pistage en arrière-plan.
- Trafic strictement fonctionnel : les paquets réseau (comme ICMP, DNS ou MQTT) ne quittent votre téléphone que lorsque vous déclenchez activement un outil. Les utilitaires externes, comme les tests de débit et les requêtes WHOIS, se connectent directement à leurs services publics respectifs, sans serveurs de pistage intermédiaires.

**SimplyNet : parce qu'il vaut mieux mieux connaître votre réseau. Jeu de mots assumé.**
