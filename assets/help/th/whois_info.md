# "Who Is" และการแปลง DNS คืออะไร?

คุณเคยสงสัยไหมว่าใครเป็นเจ้าของเว็บไซต์อย่าง google.com จริง ๆ? หรือโทรศัพท์ของคุณค้นหาคอมพิวเตอร์ที่ถูกต้องอีกฟากหนึ่งของโลกโดยอัตโนมัติจากเพียงที่อยู่เว็บได้อย่างไร?

เมื่อคุณใช้เครื่องมือ Who Is... คุณกำลังเปิดม่านเผยให้เห็นสมุดรายชื่อทางการปกครองของอินเทอร์เน็ต มันใช้สามฟังก์ชันหลักในการสืบสวนโดเมนหรือที่อยู่ IP ใด ๆ

## 1. WHOIS คืออะไร? (ทะเบียนที่ดินดิจิทัล)

ชื่อเว็บไซต์ทุกชื่อ (เช่น yourwebsite.com) คืออสังหาริมทรัพย์ดิจิทัลชิ้นหนึ่ง เช่นเดียวกับการซื้อบ้านจริงหรือจดทะเบียนรถยนต์ คุณไม่สามารถเป็นเจ้าของโดเมนแบบไม่ระบุตัวตนโดยไม่ลงทะเบียนได้

WHOIS (ซึ่งตามตัวอักษรคือการถามว่า *"ใครรับผิดชอบโดเมนนี้?"*) คือฐานข้อมูลสาธารณะขนาดใหญ่ที่บันทึกรายละเอียดความเป็นเจ้าของของทุกชื่อโดเมนและที่อยู่ IP ที่ลงทะเบียนบนโลกใบนี้

### การเปรียบเทียบ: กรมการขนส่งหรือทะเบียนอสังหาริมทรัพย์

เมื่อคุณค้นหาป้ายทะเบียนที่กรมการขนส่ง คุณจะได้บันทึกว่าใครเป็นเจ้าของรถ จดทะเบียนเมื่อใด และจะติดต่อพวกเขาอย่างไร การค้นหา WHOIS ทำสิ่งเดียวกันทุกประการสำหรับเว็บไซต์

### มันแสดงข้อมูลอะไรให้คุณเห็นบ้าง?

* ผู้ลงทะเบียน (Registrant): ชื่อของบุคคลหรือบริษัทที่ซื้อโดเมน (หมายเหตุ: หลายคนใช้บริการ "ปกป้องความเป็นส่วนตัว" เพื่อซ่อนที่อยู่บ้านส่วนตัว แต่รายละเอียดของบริษัทโฮสติงจะยังคงมองเห็นได้)
* วันที่สำคัญ: วันที่ซื้อชื่อเว็บไซต์ครั้งแรก อัปเดตครั้งล่าสุดเมื่อใด และ—สำคัญที่สุด—หมดอายุเมื่อใด
* ผู้รับจดทะเบียน (Registrar): "ร้าน" ดิจิทัลที่เจ้าของซื้อโดเมน (เช่น GoDaddy, Namecheap หรือ Google Domains)

## 2. การแปลง DNS คืออะไร? (สมุดโทรศัพท์ของอินเทอร์เน็ต)

คอมพิวเตอร์เก่งคณิตศาสตร์อย่างเหลือเชื่อ แต่ห่วยเรื่องภาษา พวกมันไม่เข้าใจชื่ออย่าง `netflix.com` เพื่อพูดคุยกัน พวกมันใช้พิกัดตัวเลขที่เรียกว่าที่อยู่ IP (เช่น `142.250.190.46`)

ในทางกลับกัน มนุษย์เก่งเรื่องชื่อ แต่ห่วยในการจดจำสตริงตัวเลขแบบสุ่ม

**การแปลง DNS (Domain Name System)** คือสะพานเชื่อมระหว่างสองโลกนี้ มันแปลชื่อที่เป็นมิตรกับมนุษย์ให้เป็นตัวเลขที่เป็นมิตรกับคอมพิวเตอร์

### การเปรียบเทียบ: แอปรายชื่อในโทรศัพท์ของคุณ

เมื่อคุณต้องการโทรหาเพื่อนของคุณชื่อ Alex คุณไม่ได้จดจำเบอร์โทรศัพท์ 10 หลักของเขา คุณเพียงแตะ "Alex" ในรายชื่อผู้ติดต่อ แล้วโทรศัพท์ของคุณจะแปลชื่อนั้นเป็นเบอร์โทรศัพท์ตัวเลขและโทรออกโดยอัตโนมัติ

* DNS คือรายชื่อผู้ติดต่อระดับโลกสำหรับอินเทอร์เน็ตทั้งหมด * เมื่อคุณค้นหาโดเมนในแอปของเรา การแปลง DNS จะทำงานทันทีในเบื้องหลัง โดยบอกคุณว่า: "เฮ้ ตอนนี้ google.com ทำงานอยู่ที่เบอร์โทรศัพท์ 142.250.190.46"

## 3. การแปลงย้อนกลับคืออะไร? (Caller ID ดิจิทัล)

แต่จะเกิดอะไรขึ้นหากคุณมีตัวเลข (ที่อยู่ IP) และต้องการทราบชื่อ (เว็บไซต์)? นี่คือจุดที่การแปลงย้อนกลับ (หรือที่รู้จักในชื่อ Reverse DNS หรือการค้นหา PTR) เข้ามามีบทบาท

หากคอมพิวเตอร์แปลกหน้ากำลังพยายามเชื่อมต่อกับเครือข่ายบ้านของคุณ หรือคุณเห็นที่อยู่ IP แปลก ๆ ในบันทึกเครือข่ายของคุณ คุณสามารถวางที่อยู่ IP นั้นลงในเครื่องมือของเราได้ แอปจะถามสมุดรายชื่อระดับโลกว่า: "ชื่อเว็บไซต์ใดที่ลงทะเบียนไว้กับหมายเลขเฉพาะนี้?"

### การเปรียบเทียบ: Caller ID (หรือการค้นหาเบอร์โทรศัพท์ย้อนกลับ)

หากโทรศัพท์ของคุณดังและแสดงหมายเลขที่ไม่รู้จักอย่าง `1-800-555-0199` คุณอาจลังเลที่จะรับ แต่หาก Caller ID ของโทรศัพท์แปลหมายเลขนั้นและแสดง **"Apple Support"** คุณก็รู้ทันทีว่าใครโทรมา

* การแปลงย้อนกลับคือ Caller ID สำหรับที่อยู่อินเทอร์เน็ต
* มันช่วยให้คุณแปลหมายเลขที่ไม่ระบุตัวตนและน่ากลัวอย่าง `172.217.16.142` กลับเป็นชื่อที่เป็นมิตรและจดจำได้อย่าง `google.com`

## สรุปเครื่องมือ "Who Is..."

โดยการรวมสามคุณสมบัตินี้เข้าด้วยกัน เครื่องมือของเราให้ "การตรวจสอบประวัติ" ที่สมบูรณ์เกี่ยวกับเป้าหมายดิจิทัลใด ๆ:

1. การแปลง DNS บอกคุณถึงที่อยู่ IP ("เบอร์โทรศัพท์") ของชื่อเว็บไซต์
2. การแปลงย้อนกลับบอกคุณถึงชื่อเว็บไซต์ ("Caller ID") ของที่อยู่ IP ลึกลับ
3. WHOIS บอกคุณถึงเจ้าของทางกฎหมายที่แท้จริง ผู้รับจดทะเบียน และวันหมดอายุของทรัพย์สินนั้น
