# การทดสอบความเร็ว

SimplyNet วัดการเชื่อมต่ออินเทอร์เน็ตของคุณโดยการถ่ายโอนข้อมูลไปและกลับจากเซิร์ฟเวอร์ทดสอบและจับเวลา มีการรายงานตัวเลขสามค่า:

- **ดาวน์โหลด** — ความเร็วที่ข้อมูลมาถึงอุปกรณ์ของคุณ หน่วยเป็น Mbps ยิ่งสูงยิ่งดี
- **อัปโหลด** — ความเร็วที่อุปกรณ์ของคุณส่งข้อมูลออกไป หน่วยเป็น Mbps ยิ่งสูงยิ่งดี
- **Ping** — ความหน่วงในการเดินทางไปกลับถึงเซิร์ฟเวอร์ หน่วยเป็นมิลลิวินาที ยิ่งต่ำ
  ยิ่งดี

## การเลือกผู้ให้บริการ

เมนูดรอปดาวน์ใต้ปุ่ม **เริ่มการทดสอบ** ใช้เลือกว่าจะใช้แบ็กเอนด์ทดสอบ

## การเปรียบเทียบบริการทดสอบความเร็ว

| คุณสมบัติ | Cloudflare (ค่าเริ่มต้น) | Ookla |
|---|---|---|
| เป้าหมายการวัด | ความเร็วการท่องเว็บที่แท้จริง | ความจุตามทฤษฎีสูงสุดของสายสัญญาณ |
| สถานะความเป็นส่วนตัว | ไม่ระบุตัวตน 100% ไม่มีการติดตาม | เก็บ IP, ตำแหน่ง และข้อมูลอุปกรณ์ |
| วิธีทางเทคนิค | การดาวน์โหลดแบบก้าวหน้าสตรีมเดียว | การทำให้เครือข่ายอิ่มตัวแบบหลายสตรีม |
| เหมาะสำหรับ | การประเมินประสิทธิภาพอินเทอร์เน็ตประจำวัน | การตรวจสอบความเร็วที่ ISP โฆษณา |

### ผ่าน Cloudflare (ค่าเริ่มต้น)

ใช้เอนด์พอยต์สาธารณะ `speed.cloudflare.com` ของ Cloudflare ไม่ต้องมีบัญชีหรือการยินยอมเพิ่มเติม และไม่มีการแชร์ตัวระบุส่วนบุคคลใด ๆ นอกเหนือจากข้อมูลปกติที่คำขอไปยังเว็บไซต์ใด ๆ พกพาไป (เช่นที่อยู่ IP ของคุณ ซึ่งจำเป็นสำหรับการส่งการตอบกลับ)

นี่คือตัวเลือกที่แนะนำสำหรับผู้ใช้ส่วนใหญ่

### ผ่าน Ookla

ใช้เครือข่ายเซิร์ฟเวอร์ speedtest.net ระดับโลกของ Ookla ซึ่งเป็นโครงสร้างพื้นฐานเดียวกับที่อยู่เบื้องหลังบริการ Speedtest ที่รู้จักกันดี เซิร์ฟเวอร์ Ookla ดำเนินการโดยบุคคลที่สามทั่วโลก ดังนั้นการทดสอบจะเชื่อมต่อกับเซิร์ฟเวอร์ที่ใกล้ที่สุดและเข้าถึงได้

เนื่องจากสิ่งนี้เกี่ยวข้องกับเซิร์ฟเวอร์ของบุคคลที่สาม การเลือก Ookla จะขอการยินยอมจากคุณในครั้งแรก **Ookla เก็บและแชร์ที่อยู่ IP, ตัวระบุอุปกรณ์ และข้อมูลตำแหน่งของคุณ** ตัวเลือกของคุณจะถูกจดจำเพื่อไม่ให้ถามอีก คุณสามารถกลับไปใช้ Cloudflare ได้ทุกเมื่อ

เมื่อ Ookla ทำงานอยู่ ปุ่ม **เริ่มการทดสอบ** จะเปลี่ยนเป็นสีเหลืองอำพันเพื่อเตือนว่ากำลังใช้แบ็กเอนด์ของบุคคลที่สาม Cloudflare จะคืนค่าปุ่มเป็นสีน้ำเงิน

## เคล็ดลับเพื่อผลลัพธ์ที่แม่นยำ

- ทดสอบผ่าน Wi-Fi หรือข้อมูลมือถือ ขึ้นอยู่กับสิ่งที่คุณต้องการวัด
- ปิดแอปอื่น ๆ ที่อาจกำลังใช้เครือข่าย
- รันการทดสอบหลาย ๆ ครั้ง—ผลลัพธ์จะแตกต่างกันไปตามสภาพเครือข่ายและภาระของเซิร์ฟเวอร์
- การเชื่อมต่อความเร็วสูงมากอาจถูกจำกัดโดยอุปกรณ์หรือวิธีการทดสอบ แทนที่จะเป็นการเชื่อมต่อจริงของคุณ

## ความเป็นส่วนตัว

ผลลัพธ์จะถูกจัดเก็บบนอุปกรณ์ของคุณเท่านั้น ภายใต้ **การวัดก่อนหน้า** คุณสามารถล้างข้อมูลเหล่านั้นได้ทุกเมื่อจากส่วนประวัติ SimplyNet ไม่อัปโหลดผลลัพธ์ของคุณไปที่ใด
