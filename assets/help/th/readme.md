# SimplyNet: เครื่องสแกนและวิเคราะห์เครือข่าย

## 🔍 ค้นพบทุกอุปกรณ์บนเครือข่ายของคุณ

เคยสงสัยไหมว่ามีอะไรเชื่อมต่อกับ WiFi ของคุณจริง ๆ บ้าง? SimplyNet ช่วยให้คุณเห็นภาพรวมเครือข่ายของคุณอย่างครบถ้วนภายในไม่กี่วินาที

## มันทำอะไรได้บ้าง?

- ✓ สแกนเครือข่าย — ค้นหาโฮสต์ที่ทำงานอยู่ทั้งหมดใน LAN ของคุณด้วยความเร็วสุดขั้ว
- ✓ สแกนพอร์ต — ตรวจสอบว่ามีบริการใดกำลังทำงานอยู่บนโฮสต์ใด ๆ
- ✓ วิเคราะห์เครือข่าย — มี Ping, การค้นหา DNS และเครื่องมือขั้นสูงในตัว
- ✓ ค้นหาและทดสอบอุปกรณ์ IoT ของคุณ — สมัครรับ (Subscribe) และเผยแพร่ (Publish) บนโบรกเกอร์ MQTT

## ทำไมคุณถึงจะหลงรักมัน

- เร็วสุด ๆ — การสแกนเสร็จภายในไม่กี่วินาที
- ไม่รกตา — อินเทอร์เฟซที่สะอาดและใช้งานง่าย
- ทำงานใน LAN — ไม่ต้องใช้คลาวด์ ไม่มีการติดตาม
- บันทึกล็อกได้ยืดหยุ่น — เปิด/ปิดการบันทึก ดูย้อนหลังได้ว่าเกิดอะไรขึ้นเมื่อไร
- เป็นมิตรกับนักพัฒนา — เหมาะทั้งสำหรับมืออาชีพด้านไอทีและผู้ใช้ที่อยากรู้อยากเห็น
- ฟรี 100% — ไม่มีโฆษณา ไม่มีการติดตาม ไม่มีการรบกวน ยินดีรับการบริจาค
- ไม่มีเรื่องไร้สาระ — มีเฉพาะเครื่องมือที่มีประโยชน์และใช้งานได้จริงเท่านั้น
- โอเพนซอร์ส — การพัฒนาที่โปร่งใสและขับเคลื่อนโดยชุมชน [ดูซอร์สโค้ด](https://github.com/igrowing/SimplyNet) ได้ทุกเมื่อ คลิก ⭐ "Star" 😊
- แปลแล้ว 15 ภาษา

## เหมาะสำหรับ

- 🏠 การจัดการเครือข่ายในบ้าน — รู้ว่ามีอะไรอยู่บน WiFi ของคุณ
- 🔒 ความปลอดภัยของเครือข่าย — ตรวจจับอุปกรณ์ที่ไม่คาดคิด
- 👨‍💻 มืออาชีพด้านไอที — วิเคราะห์และแก้ปัญหาได้อย่างรวดเร็ว
- 🛠️ ผู้ดูแลระบบเครือข่าย — เครื่องมือเครือข่ายที่ขาดไม่ได้ในกระเป๋าของคุณ
- 🧪 ผู้ที่หลงใหลในเทคโนโลยี — สำรวจว่าเครือข่ายของคุณทำงานอย่างไร

## ความเป็นส่วนตัวมาก่อน

- ข้อมูลของคุณยังคงเป็นของคุณ: ล็อกการสแกน ประวัติ และโปรไฟล์เครือข่ายของคุณถูกบันทึกไว้ในที่จัดเก็บข้อมูลภายในอุปกรณ์เท่านั้น
- ไม่มีการติดตามหรือการวิเคราะห์จากบุคคลที่สาม: แอปนี้ไม่มีเทเลเมทรี ไม่มีโฆษณา และไม่มีเฟรมเวิร์กการติดตามเบื้องหลังใด ๆ
- การรับส่งข้อมูลเฉพาะที่จำเป็นเท่านั้น: แพ็กเก็ตเครือข่าย (เช่น ICMP, DNS หรือ MQTT) จะออกจากโทรศัพท์ของคุณก็ต่อเมื่อคุณเรียกใช้เครื่องมืออย่างตั้งใจเท่านั้น เครื่องมือภายนอกอย่างการทดสอบความเร็วและการสอบถาม WHOIS จะเชื่อมต่อโดยตรงกับบริการสาธารณะที่เกี่ยวข้อง โดยไม่มีเซิร์ฟเวอร์ติดตามคั่นกลาง

**SimplyNet: เพราะคุณควรจะรู้จักเครือข่ายของคุณให้ดีขึ้น ตั้งใจเล่นคำนะ**
